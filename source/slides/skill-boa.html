Como escrever uma boa skill

A description é o gatilho

Diga quando usar, não o que é. É só ela que o modelo lê para decidir.

Corpo curto e procedural

Passos numerados, não teoria. O modelo já sabe o que é IDOR.

Determinístico vai em script

O modelo chama o script; não reimplementa a lógica a cada vez.

# Caça a IDOR
1. Liste endpoints com IDs em recon/endpoints.txt
2. Capture a request com a conta A
3. Rode scripts/swap_ids.py com a sessão da conta B
4. Compare status e corpo das respostas
5. Diferença real? Salve em findings/ e chame
   o agente validador
