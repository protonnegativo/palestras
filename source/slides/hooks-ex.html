Exemplo: o settings.json do harness

.claude/settings.json
{
  "permissions": {
    "allow": ["Bash(httpx:*)", "Bash(katana:*)"],
    "ask":   ["Bash(nuclei:*)", "Bash(ffuf:*)"],
    "deny":  ["Bash(sqlmap:*)", "Read(./.env)"]
  },
  "hooks": {
    "PreToolUse": [{
      "matcher": "Bash",
      "hooks": [{ "type": "command",
                 "command": "./check_scope.sh" }]
    }]
  }
}

allow: roda sem pedir confirmação.

ask: pergunta para você antes de rodar.

deny: bloqueado, mesmo que o modelo insista.

hooks: um comando seu roda antes de cada chamada. Se ele sair com código 2, a ação é bloqueada e o motivo volta ao modelo.
