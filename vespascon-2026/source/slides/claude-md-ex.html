# Harness de bug bounty

## Escopo
- Alvos: scope/targets.txt (fonte única)
- Fora de escopo: scope/out-of-scope.txt
- Máx. 5 req/s por host. Nada de DoS ou brute force.

## Regras
- Nenhum achado sai sem PoC reproduzido pelo validador.
- Nunca altere dados de terceiros: use contas próprias.

## Saídas
- Evidências em findings/<id>/ (request, response, PoC)
- Relatório no modelo templates/report.md

## Metodologia
- Está em .claude/skills/. Leia a skill antes de testar.

Aponte para arquivos em vez de colar listas no texto.

Proibições claras, sem "evite" nem "se possível".

Diga onde está o resto: o CLAUDE.md é o índice.
